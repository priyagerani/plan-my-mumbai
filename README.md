# Plan My Mumbai — AI-Native Event Architecture Platform

> The serene, luxury event planner for weddings, milestone birthdays, and community celebrations across Mumbai. Powered by grounded local data and Google Gemini.

## 🌐 Live Website
👉 **Experience the Live App:** [https://plan-my-mumbai.vercel.app](https://plan-my-mumbai.vercel.app)

---

## ✨ Four Core Capabilities

1. **🔒 3-Tier Dynamic Budget Architecture**
   - Segmented priority control (🔒 Non-Negotiable, ⭐ Important, 💸 Flexible).
   - Grounded in current Mumbai market rates across Bandra, Juhu, Powai, Dadar, Thane, and Colaba.
   - Built-in Budget Reality Check with transparent trade-offs and savings reasoning.

2. **🏛️ Curated Mumbai Venues & pan-Mumbai Catering**
   - Grounded venue matching by guest capacity, budget fit, and must-ask questions.
   - Pan-Mumbai catering options with per-plate math and dietary purity badges (Pure Veg & Jain).

3. **📅 Dual Actionable Timelines**
   - Multi-week countdown & day-of hour-by-hour run of show.

4. **🤝 Shortlist Concierge**
   - Direct assisted inquiry capture for venue and caterer introductions.

---

## 🛠️ Built With
- **Frontend:** Responsive HTML5, Editorial Luxury CSS, Vanilla JavaScript
- **Backend:** Node.js Serverless Runtime
- **AI Intelligence:** Google Gemini API with Grounded Mumbai Datasets
- **Deployment:** Vercel Global CDN (24/7 Uptime)
