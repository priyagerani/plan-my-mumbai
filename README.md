## 🚀 24/7 Permanent Deployment to Vercel
1. Push this folder to your GitHub repository.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Select your repository — Vercel will automatically detect `vercel.json` and deploy it with your permanent URL (e.g. `https://plan-my-mumbai.vercel.app`).
4. (Optional) Add your `GEMINI_API_KEY` in Vercel Environment Variables.

## 🛠️ Local Execution
```bash
node server.js
```
